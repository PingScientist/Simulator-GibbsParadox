02 三個閱讀重點

看見混合，也理解數字的意義

A

先比較 A+B 與 A+A

在相同參數與種子下，粒子運動相同。改變物種的可分辨性，會改變熱力學計數。A+A 即使左右來源完全混合，也沒有廣延的組合混合熵。

再打開磁性作用

箭頭表示偶極方向。頭尾平行偏好吸引，並排平行偏好排斥。改變 C*/T* 會改變構型偏好；取樣路徑不能用來量測真實的混合速率。

固定種子可重現結果。先在閉合隔板下取樣，再移除隔板；觀察較長區間、多組種子。用 CSV 保留資料，勿把單次波動解讀成第二定律失效。

03 物理模型與作業問答

公式、假設與適用範圍

01這個實驗實際算了什麼？

固定溫度的正則取樣

對稱地提議粒子位移與轉向，以 Pacc=min[1, exp(−ΔU/kBT)] 接受。越界、跨越未開隔板或硬核重疊直接拒絕。初始隨機配置需經取樣鬆弛。動畫以 sweeps 表示，沒有校準成真實時間。

Uij = C/r³ [cos(θi−θj) − 3cos(θi−φ)cos(θj−φ)]

φ 是兩粒子連線方位角。磁性模式在 r<σ 時 U=∞；所有粒子對都計算，無截斷。隔板阻擋粒子，但不屏蔽偶極作用。理想模式的點粒子 U=0。

三種讀值，三種意義

ΔSmix = −kB ∑α Nα ln xα

適用於等溫、初始同數密度、作用勢不依物種而變的均勻體相。兩種等量物種 xA=xB=1/2；同種粒子無此組合項。

m = ∑g=L₀,R₀ (Ng/Ntot) h(ng,L/Ng)

h(p)=−p ln p−(1−p)ln(1−p)，0 ln 0=0。m 是來源群的左右分布指標，忽略位置、方向及粒子間相關性；U 則是當前所有粒子對的位能和。

02短程作用的位能會影響混合熵嗎？動量呢？

位能一般會影響構型熵。本例 A、B 的作用完全相同，且比較等溫、等密度的均勻體相，因此前後相同的體相交互作用貢獻相消，留下組合混合項。短程這個條件本身不足以保證相消；若 uAA、uAB、uBB 不同，或結構、密度、相態改變，就不能直接套用。

對 H=K(p)+U(q)，配分函數的動量積分可分離；前後 T、各物種粒數與質量不變時，其熵差為零。這是動量項相消，並非動量不存在。

本頁的 0 與 ln 2 是熱力學極限基準。有限粒子數、容器邊界及撤去硬核隔板後可達面積的改變，均可帶來額外修正。二維的 r⁻³ 遠距尾部可積分；三維情形不能直接照搬此短程判準。

03Einstein 固體需要再除以 N! 嗎？

相同原子仍不可分辨；標準 Einstein 模型已以可區分的晶格站點振動態計數，一個站點局域一個原子，不再額外除以 N!。若先把有標記的原子分配至站點，N! 種分派會與 Gibbs 因子 1/N! 抵消。

Ω(q,M) = (q+M−1)! / [q!(M−1)!]

一維 N 個站點對應 M=N 個振子；三維 N 個原子對應 M=3N。不可把原子數和振子數混為一談。

04為什麼需要 1/N!？

理想氣體若把同種粒子的置換重複計入，Z∝VN；同時放大 N 與 V 時，多出 N ln N 類型的非廣延項。加入 1/N! 後，用 Stirling 近似可得到 S∝N ln(V/N)+N×常數，恢復熱力學極限的廣延性。

有限 N 時保留精確階乘會有次廣延修正；因此「同種混合熵為零」指沒有與 N 成正比的組合混合項，不表示每一個有限系統撤板過程都嚴格零熵變。
